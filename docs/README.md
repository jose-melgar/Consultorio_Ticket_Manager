Medical Office Ticket & Data Manager
Automated billing and record-keeping system for healthcare providers.

This project streamlines the administrative workflow of a medical clinic by converting free-text service descriptions into actionable data. It leverages Python to bridge the gap between manual notes and structured digital records.

Smart Extraction: Uses Regex to identify services, supplies, and quantities from natural language.

Excel Integration: Uses Excel as a lightweight, portable database for catalogs and sales tracking.

Thermal Print Ready: Generates dynamic PDFs formatted for 80mm thermal printers with physical validation borders.

Scalable Architecture: Designed with a modular core to separate business logic from hardware implementation.
